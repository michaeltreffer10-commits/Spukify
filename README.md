# CO3

Ein Case-Opening-Spiel im Browser, inspiriert von Counter-Strike 2. Alle Skins, Namen und Grafiken sind selbst gemacht.

## Was man machen kann

- **8 Cases** (Spuk, Pixel, Frost, Dschungel, Neon, Galaxie, Inferno, Gold) mit über 140 Skins
- **Schlüssel**: Zum Öffnen braucht man 1 Case + 1 Schlüssel. Cases droppen beim Spielen oder sind günstig zu kaufen, Schlüssel muss man kaufen. Fehlendes wird beim Öffnen automatisch gekauft
- **Waffen im CS2-Look**: 35 selbst gezeichnete Modelle (AK-47, M4A4, AWP, Deagle, Messer, Handschuhe …) mit Lack, Metall und Kunststoff, in 2D und 3D
- **Sticker-Kapseln**: 3 Kapseln mit Papier-, Glitzer-, Holo- und Gold-Stickern. Bis zu 4 Sticker pro Waffe aufkleben (auch in 3D sichtbar) oder abkratzen
- **Öffnen**: 3D-Kiste per Leertaste spammen aufbrechen (Handy: tippen; abschaltbar), Band mit Bewegungsunschärfe, Nachfedern und fiesen Beinahe-Treffern, Konfetti bei seltenen Drops
- **Massen-Öffnen**: 1, 5, 10 oder 100 auf einmal, oder ohne Animation mit „Schnell öffnen“
- **Münzen verdienen**: Geldpresse (druckt auch, wenn das Spiel zu ist, mit Upgrades), stündlicher Bonus, Tagesbonus, vier Minispiele (Aim, Kopfschuss, Bombe, Reaktion) mit Case- und Kapsel-Drops
- **Level, tägliche Missionen, Sammelalbum und über 40 Erfolge**
- **Zufalls-Ereignisse**: Glücksstunde, Rabattaktion, Doppel-XP, Händler-Wahnsinn und Münzregen
- **Kommentator und Meme-Sounds**: Sprüche zu jedem Drop, Airhorn, trauriges Posaunen-Wah-wah und Sprachansagen (abschaltbar)

Alle Sounds werden live im Browser erzeugt, alle Grafiken, Sticker und 3D-Modelle sind selbst gebaut. Teams und Skins sind ausgedacht.

## Chancen

| Seltenheit | Chance |
|---|---|
| Militärstandard (blau) | 85 % |
| Limitiert (lila) | 12 % |
| Klassifiziert (pink) | 2,5 % |
| Verdeckt (rot) | 0,45 % |
| ★ Außergewöhnlich (Messer/Handschuhe) | 0,05 % (1 zu 2.000) |
| ??? | 1 zu 50.000 |

Sticker-Kapseln: Papier 80 %, Glitzer 16 %, Holo 3,2 %, Gold 0,8 %.

## Starten

```bash
npm install
npm run dev
```

Bei jedem Push auf `main` oder den Arbeits-Branch wird das Spiel automatisch auf GitHub Pages veröffentlicht.
